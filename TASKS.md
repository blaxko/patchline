The one real code change: **fixed a genuine production bug found while writing this step's test**, in `services/backend/src/realtime/gateway.ts`'s `registerGateway()` — the browser-facing `socket.on("message", ...)` handler (which feeds both the AssemblyAI adapter and the regression audio buffer) was registered only *after* several `await`s (session insert, `adapter.connect()`), so any audio frames a real client sent the instant its WebSocket opened — exactly what the Call UI's `useVoiceSession.ts` does — could be silently dropped before that handler ever existed. ### 1. Fixed the MOCK_ASSEMBLYAI silent-default bug (not just documented it)
